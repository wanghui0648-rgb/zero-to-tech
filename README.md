# 第一次项目 - 我的第一个 Web 网页

这是一个基础的前端网页项目，演示了如何将 HTML 页面结构、CSS 样式设计与 JavaScript 动态交互逻辑进行模块化分离与整合。

## 📁 目录结构

```text
第一次项目/
├── index.html     # 页面结构 (HTML)
├── style.css      # 页面样式 (CSS)
├── script.js      # 交互脚本 (JavaScript)
└── readme.md      # 项目说明文档
```

## ✨ 功能特性

1. **页面布局与结构** (`index.html`)：
   - 包含卡片容器 (`.card`)、标题、提示文本与交互按钮。

2. **样式设计与视觉呈现** (`style.css`)：
   - 使用 **Flexbox** 布局实现页面垂直与水平居中。
   - 使用渐变背景、卡片阴影 (`box-shadow`) 和圆角 (`border-radius`) 提高现代感。
   - 为按钮增加了鼠标悬停 (`:hover`) 效果。

3. **动态交互逻辑** (`script.js`)：
   - 封装 `changeText()` 函数。
   - 点击“点我试试”按钮时，通过 DOM 操作更新文本内容。

## 🚀 运行方式

- **直接打开**：用浏览器直接双击打开 `index.html` 即可预览效果。
- **开发环境预览**：在 Antigravity IDE / VS Code 中右键 `index.html`，选择 **Open with Live Server** 体验实时更新预览。

## 🛠️ 技术栈

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
